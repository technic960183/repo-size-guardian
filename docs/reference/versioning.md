# Versioning reference

Which version to put after `uses: technic960183/repo-size-guardian@`.

| Version | Runs | Use when |
|---|---|---|
| `v1` | The latest `1.x` release. | Most workflows: you get fixes without editing the workflow. |
| `v1.0.0` | Exactly that release. | You want to upgrade on your own schedule. |
| A full commit SHA | Exactly that commit. | Your organization requires actions pinned to a SHA. |

Each release and its changes are listed on the
[Releases page](https://github.com/technic960183/repo-size-guardian/releases).
